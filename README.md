# 二分探索ラボ

商業科「プログラミング」〔指導項目〕(3) アルゴリズム カ 配列の利用 の本時
「誕生日当てクイズから考える探索の仕組み（二分探索）」をアシストする授業用Webアプリ。
教員はプロジェクタで投影、生徒はスマホ・タブレットで触る想定。

配布先: <https://mkt918.github.io/binary-search-lab/>

授業設計（ルール・数値・8ステップ）は [docs/26-09-26_二分探索授業_構成まとめ.md](docs/26-09-26_二分探索授業_構成まとめ.md) が正本。

## 使い方

`index.html` をブラウザで開くだけ。ビルド不要・サーバー不要（`file://` でも動く）。
Google Fonts が読めない環境でもシステムの丸ゴシックで表示される。

右上の「文字 大」で投影用に文字を125%に拡大（端末ごとに記憶）。

## 画面（ナビの番号＝授業の流れ）

| # | 画面 | ワークシート | 内容 |
|---|---|---|---|
| 1 | 誕生日当て | 1・2・3 | 大きめのカレンダー（タップ・ドラッグ両対応、横に入りきらない分は枠内スクロール）で消したい範囲を自分で選び、「選んだ範囲を消す」で候補から外していく。予想回数・出題者名を入れて記録を残せる（端末内保存） |
| 2 | 箱の鍵さがし | 4 | 4/8/16個の箱。箱を選んで「〇番より後？」か「宣言」。全パターン確認表（あなたの回数）。決定木へジャンプすると見つけた鍵への道すじが光る |
| 3 | 線形探索と比較 | 5 | 同じ鍵の位置で線形探索と二分探索を1秒ごとに同時進行。鍵の場所ごとの回数表（最大8/3・平均4.5/3） |
| 4 | 決定木 | 完成図 | 箱2〜16個の決定木をSVGで描画。「半分に分ける／端から聞く」切替、1段ずつ表示（8個→4個→2個→1個）、葉タップで道すじ強調 |
| 5 | n個・大きな数 | 6・7 | n入力＋対数スライダー＋プリセット（2〜100万、365）。半分ずつ減る連鎖、2の累乗表（2¹〜2²⁰）で該当セルを強調、【ログ】の説明。ワークシート6・7の表は「？」タップで答えを表示。1回1秒なら何日かかるかの比較 |
| 6 | 並びが大事 | まとめ | バラバラのカードで二分探索すると「あるのに見つからない」ことを実演→並べ替えると見つかる。次時（整列）へ |
| 7 | まとめ・豆知識 | 8 | まとめ4点、豆知識の読み上げ文、今日のルール方式と一致確認あり方式（本物のプログラム）の回数比較（最良1・最悪4・平均2.625）と二分探索木 |

## ルール（全画面共通・変更時は docs の 0-1 を必ず確認）

- 質問は「〇より後ですか？」の比較質問のみ。「その日ちょうど」は「いいえ」。
- 宣言は1回だけ、外れたら失敗、質問回数に数えない。
- → 候補 n 個を必ず当てられる回数は ⌈log₂n⌉。

## ファイル構成

```
index.html        全画面（ハッシュでページ切替）
css/tokens.css    デザイントークン（Hallmark playful / Hum）。色はすべてここ経由
css/style.css
js/logic.js       ルール・計算の純粋関数（DOM非依存、window.BS / module.exports）
js/tree.js        決定木のSVG描画（window.BSTree）。opts.terms で場面の言い換え語を差し替え可能
js/app.js         各画面の制御
js/tests.js       logic.js のテスト（数値は docs の 0-4 表と一致させる）
tests.html        ブラウザでテスト結果を見る
docs/             授業の構成まとめ（設計の正本）
```

ES Modules を使わず通常の `<script>` で読み込んでいるのは、`file://` で開いても動かすため。

## テスト

```bash
node js/tests.js
```

または `tests.html` をブラウザで開く。
